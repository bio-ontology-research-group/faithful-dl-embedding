# Experiment Datasets (`experiments/data/`)

This directory contains the deterministic dataset generators and committed small OWL splits used in the learnable geometric embedding experiments (Spec §5.1).

## 1. Synthetic Helly Suite (`tk3`, `tk4`, `tk5`, `tk6`)

Generated by `experiments/data/make_synthetic.py` into `experiments/data/synthetic/tk{k}.owl` (`k in {3, 4, 5, 6}`), namespace `http://mowl.borg/geo#`:

- Concept names `X_1, ..., X_k`.
- For each `i in 1..k`, a concept name `A_i ≡ ⊓_{j != i} X_j` representing the `(k - 1)`-fold conjunction of all `X_j` except `X_i`. For `k >= 4`, the `(k - 1)`-ary intersection is binary-normalised with shared auxiliary equivalence names `Aux_<idx_1>_..._<idx_m> ≡ left ⊓ right` so that `mowl.geometric.normalise` preserves both inclusion directions of each intermediate binary conjunction.
- Pairwise disjointness axioms `A_i ⊓ A_j ⊑ ⊥` for all `1 <= i < j <= k`.
- One declared unconstrained concept name `Z`.
- Task: `satisfaction` (no held-out validation or test axioms).

### Certificate Structure on `T_k`

- **`tk3` (`k = 3`)**: `A_1 ≡ X_2 ⊓ X_3`, `A_2 ≡ X_1 ⊓ X_3`, `A_3 ≡ X_1 ⊓ X_2`. All three pairwise conjunctions of `{X_1, X_2, X_3}` are directly named by `NF2` equivalences, so both `certificate_triangles(cm)` and `helly_check(cm, k_max=3)` return the unique non-degenerate certificate over `(X_1, X_2, X_3)`.
- **`tk4..tk6` (`k >= 4`)**: `T_k` names its `(k - 1)`-wise conjunctions rather than all three pairwise edges of an unsatisfiable 3-clique, and every 3-subset of `{X_1..X_k}` is satisfiable. Consequently, `certificate_triangles(cm)` returns `[]`, while `helly_check(cm, k_max=k)` finds the minimal unsatisfiable set of size `k` as a non-degenerate `HellyCertificate` with `c1=(X1,)`, `c2=(X2,)`, `c3=(X3, ..., Xk)` and `pairwise_names=(Aux_1_2, A2, A1)`.

## 2. Pizza-EL Subsumption Benchmark (`pizza`)

Generated by `experiments/data/make_pizza.py` from `<data-dir>/gfe-data/pizza/pizza.owl` (default `<data-dir> = ~/tmp`) into `<data-dir>/gfe-data/pizza-el/` (and mirrored into `experiments/data/pizza-el/`, `317,650` bytes total):

1. Normalise `pizza.owl` into its EL++ fragment via `mowl.geometric.normalise` (`662` normalised axioms across `109` concept names and `8` roles; `52` non-EL++ axioms dropped).
2. Build the canonical model `cm_full` of the full EL++ fragment (`106` satisfiable concept names including `owl:Thing` and `8` auxiliary normaliser classes under `http://mowl.borg/aux/`; `2` unsatisfiable concept names `CheeseyVegetableTopping` and `IceCream`; `97` satisfiable original non-auxiliary named classes).
3. Collect candidate asserted atomic subsumptions by taking the `84` raw `SubClassOf(named, named)` axioms of `pizza.owl` and intersecting with the `97` satisfiable non-auxiliary named classes (`81` candidate axioms; excludes the `3` raw subsumptions with an unsatisfiable subclass and never includes `NF1` projections of `EquivalentClasses` definitions such as `SpicyPizza ⊑ Pizza`, `CheeseyPizza ⊑ Pizza`, or `MeatyPizza ⊑ Pizza`, per Ruling I2).
4. Permute candidates with `numpy.random.default_rng(0)`. Because a `10 % / 10 %` split yields `round(0.10 * 81) = 8 < 20` test axioms, the split fractions are raised to `20 % / 20 %` per Spec §7, yielding `16` validation axioms (`valid.owl`), `16` test axioms (`test.owl`), and `630` remaining training axioms (`ontology.owl`, including `58` `NF1` axioms). None (`0 / 16` validation and `0 / 16` test) of the held-out axioms are entailed by the training ontology alone (trivial positives, Ruling M1).
5. Write `ontology_deductive_closure.owl` containing all `365` non-trivial atomic subsumptions `A ⊑ B` (`A != B`) entailed by `cm_full` over the `97` satisfiable non-auxiliary named classes. Auxiliary normaliser classes (`http://mowl.borg/aux/...`) stay in `ontology.owl` for training but are excluded from `ontology_deductive_closure.owl` and from `dataset.evaluation_classes` (`100` classes: `99` original Pizza named classes including `owl:Nothing` plus `owl:Thing`, Ruling I1). Subsumptions involving the `2` unsatisfiable named classes (`CheeseyVegetableTopping` and `IceCream`) are intentionally omitted from `ontology_deductive_closure.owl` (Ruling M2).
6. `load_dataset("pizza")` prefers the committed repository mirror `experiments/data/pizza-el/` over any copy in `<data-dir>/gfe-data/pizza-el/` and verifies/syncs `<data-dir>/gfe-data/pizza-el/` by SHA-256 checksum (Ruling M4).

## 3. GO and FoodOn Subsumption Benchmarks (`go`, `foodon`)

Loaded via `mowl.datasets.builtin.GOSubsumptionDataset` and `FoodOnSubsumptionDataset` with `data_root=<data-dir>/gfe-data/mowl` (Chen et al., 2020 protocol). Each tarball provides `ontology.owl`, `valid.owl`, `test.owl`, and `ontology_deductive_closure.owl`.

## 4. Dataset Statistics Generator (`dataset_stats.py`)

`python -m experiments.data.dataset_stats` recomputes and writes Sections 1–3 of `experiments/results/dataset_stats.md` across the TBox/satisfaction datasets (`tk3`–`tk6`, `pizza`, `go`, `foodon`), using `experiments.cm_cache.get_canonical_model` when present and falling back to `CanonicalModel.from_normalised` otherwise. Sections 4 and 5 of `experiments/results/dataset_stats.md` are updated by `make_yeast_function.py` and `make_helis.py`.

## 5. ABox Benchmark B1: Yeast Function Prediction (`yeast-function`)

Transforms `ontology.owl` from mOWL's `PPIYeastDataset` into an ABox function-prediction benchmark over the Gene Ontology (GO) EL++ TBox and training protein-protein interactions (`Spec §3.1`; committed manifest mirror at `experiments/data/yeast-function/manifest.json`).

### 5.1 Obtaining the Input `ontology.owl` via mOWL

Download and extract `PPIYeastDataset` into `<data-dir>/gfe-data/yeast` (default `<data-dir> = ~/tmp`):

```bash
python -c "import mowl; mowl.init_jvm('4g'); from mowl.datasets.builtin import PPIYeastDataset; PPIYeastDataset(data_root='<data-dir>/gfe-data/yeast')"
```

Pinned input file recorded in `experiments/data/yeast-function/manifest.json` (and `<data-dir>/gfe-data/yeast-function/manifest.json`):

- Path: `<data-dir>/gfe-data/yeast/ppi_yeast/ontology.owl`
- Size: `197,869,355` bytes
- SHA-256: `a7d6d713bd025672123f9c848014b86ef2fb9ecfcdbe3f7ecc3c722092343083`

### 5.2 Builder Command

```bash
python -m experiments.data.make_yeast_function \
    --input <data-dir>/gfe-data/yeast/ppi_yeast/ontology.owl \
    --out <data-dir>/gfe-data/yeast-function \
    --seed 0
```

### 5.3 Protocol & Generated Outputs in `<data-dir>/gfe-data/yeast-function/`

1. Rewrites all `6,030` yeast proteins (`http://4932.*`; `5,353` annotated with GO, `5,943` in PPI) from `OWLClass` into `OWLNamedIndividual`.
2. Normalises the GO TBox/RBox into its EL++ fragment via `mowl.geometric.normalise` (`50,713` GO classes in signature, `1` non-EL++ axiom dropped) and ensures the `3` pairwise root disjointness axioms between `GO_0008150` (`biological_process`), `GO_0003674` (`molecular_function`), and `GO_0005575` (`cellular_component`) are present.
3. Rewrites each protein function annotation `p ⊑ ∃has_function.G` into an atomic class assertion `Aux_G(p)` (`Aux_G` IRI `http://mowl.borg/yeast-function/has_function/GO_XXXXXXX`) paired with TBox axioms `Aux_G ⊑ ∃has_function.G` (`NF3`) and `∃has_function.G ⊑ Aux_G` (`NF4`), and rewrites training PPI axioms `p ⊑ ∃interacts_with.q` into `216,694` `ObjectPropertyAssertion(interacts_with, p, q)` assertions.
4. Computes the GO atomic subsumption closure with ELK, reduces the `32,114` raw annotations per protein to `30,642` most-specific leaf annotations (`1,472` ancestor annotations dropped), and splits leaf `(protein, G)` pairs `80 / 10 / 10` using `numpy.random.RandomState(0)` while keeping `402` single-leaf proteins in training (`24,594` train / `3,023` valid / `3,025` test leaf annotations; `0` entailed holdouts dropped).
5. Outputs written to `<data-dir>/gfe-data/yeast-function/` (with SHA-256 checksums recorded in `manifest.json`):
   - `ontology.owl`: Training EL++ TBox + ABox (`67,474` normalised concept names, `24,594` `Aux_G(p)` class assertions, `216,694` `interacts_with(p, q)` assertions).
   - `valid.owl`, `test.owl`: Held-out `ClassAssertion(Aux_G, p)` ontologies (`3,023` and `3,025` assertions).
   - `train_annotations.tsv`, `valid_annotations.tsv`, `test_annotations.tsv`: Tab-separated `protein_iri\tgo_iri` leaf annotations per split.
   - `candidates.txt`: The `4,447` `Aux_G` class IRIs with `>= 1` training annotation (`2,821 / 3,023` validation and `2,809 / 3,025` test positives lie inside `candidates.txt`).
   - `labels_valid.parquet` (`2,172 × 4,447 = 9,658,884` rows: `31,952` `entailed`, `9,626,932` `unknown`, `0` `contradicted`) and `labels_test.parquet` (`2,217 × 4,447 = 9,858,999` rows: `32,862` `entailed`, `9,826,137` `unknown`, `0` `contradicted`): Three-way `(individual, class, label)` tables (`contradicted = 0` by design because `∃has_function.G₁ ⊓ ∃has_function.G₂` is satisfiable even when `G₁ ⊓ G₂ ⊑ ⊥`).
   - `manifest.json`: Input/output SHA-256 digests, split counts, and timings (mirrored to `experiments/data/yeast-function/manifest.json`).

### 6.3 Range Materialisation, KB vs Gold-Conditional Label Columns, and Outputs

1. **EL++ TBox normalisation and surviving disjointness:** Normalises the TBox/RBox of `helis_v1.00.origin.owl` (`359` TBox + `3` RBox axioms) via `mowl.geometric.normalise` into `372` EL++ axioms (`261` `NF1`, `92` `NF2` [all `⊥`], `6` `NF3`, `13` `NF4`; `77` TBox and `3` RBox axioms outside EL++ dropped). Verifies that all `92` pairwise disjointness axioms survive (`91` pairs from the 14-way food-group `AllDisjoint` axiom plus `RedMeat ⊓ WhiteMeat ⊑ ⊥`).
2. **Sound `ObjectPropertyRange` → ABox materialisation:** All `15` `ObjectPropertyRange` axioms in `helis_v1.00.origin.owl` have a named range class `R`, and HeLiS contains `0` role inclusions (`0` `SubObjectPropertyOf` and `0` `SubPropertyChainOf` axioms). Because `ELNormalizer` drops `ObjectPropertyRange` axioms, `make_helis.py` materialises `R(b)` into `ontology.owl` for every kept `ObjectPropertyAssertion(r, a, b)` (`83,210` assertions across `hasNutrient`, `hasRecipeFood`, `hasFood`), which is sound in EL++ without role inclusions. This produces `17,460` unique `R(b)` assertions (`16,458` net new `ClassAssertion` axioms not already in the `14,222` positive `train.csv` assertions: `15,780` `Nutrient`, `416` `RecipeFood`, `262` `Food`), bringing `ontology.owl` to `30,680` training `ClassAssertion` axioms and turning `5,229` previously-unknown held-out `(individual, candidate)` pairs into KB-`entailed` (`+1,759` on `valid`, `+3,470` on `test`).
3. **KB (`label`) vs gold-conditional (`label_gold`) label columns in `labels_{valid,test}.parquet`:**
   - Every HeLiS individual has a single atomic class assertion in `helis_v1.00.origin.owl`, partitioned across `train.csv` (`14,222` positive rows; `14,222` label-`0` sampled negatives dropped), `valid.csv` (`2,031` rows), and `test.csv` (`4,065` rows).
   - **`label` (`unknown`, `entailed`, `contradicted`) — strictly KB-based:** Computed from the training canonical model `cm_train` (`cm_train.instance_of(a, C)`) and the `277 × 277` pairwise TBox disjointness table (`cm_tbox.joint_satisfiable`). Because held-out individuals only acquire `Recipe ⊑ Food`, `RecipeFood`, or `Nutrient` via domain/range materialisation on `hasRecipeFood`/`hasFood`/`hasNutrient`—all compatible with every food group—the strictly KB-based `label` column has `contradicted = 0` on both `valid` (`1,971` `entailed`, `560,616` `unknown`) and `test` (`3,890` `entailed`, `1,122,115` `unknown`), whereas `train` has `69,722` KB-`contradicted` pairs across `639` food-group individuals.
   - **`label_gold` (`unknown`, `entailed_gold`, `contradicted_gold`) — gold-conditional (`Spec §3.2` amendment):** Conditions on the held-out individual's ground-truth class $G_{\text{gold}}(a)$ using the TBox closure (`entailed_gold` for TBox superclasses of $G_{\text{gold}}(a)$ including itself; `contradicted_gold` for candidates $C$ with $G_{\text{gold}}(a) \sqcap C \sqsubseteq_{\mathcal{T}} \bot$; `unknown` otherwise). This yields `6,332` `entailed_gold`, `546,308` `unknown`, and `9,947` `contradicted_gold` on `valid` (`92` food-group individuals) and `12,497` `entailed_gold`, `1,093,339` `unknown`, and `20,169` `contradicted_gold` on `test` (`185` food-group individuals).
4. **Outputs written to `<data-dir>/gfe-data/helis/`:**
   - `ontology.owl`: Training EL++ TBox + ABox (`20,318` declared individuals, `277` candidate classes, `372` normalised TBox axioms, `83,210` `ObjectPropertyAssertion`s, `30,680` `ClassAssertion`s).
   - `valid.owl` (`2,031` `ClassAssertion`s) and `test.owl` (`4,065` `ClassAssertion`s).
   - `candidates.txt`: All `277` named classes from `classes.txt` (excluding `owl:Thing`).
   - `skip_valid.tsv`, `skip_test.tsv`: Per-individual comma-separated inferred classes from `inferred_classes.txt` masked during filtered ranking.
   - `labels_valid.parquet` (`2,031 × 277 = 562,587` rows) and `labels_test.parquet` (`4,065 × 277 = 1,126,005` rows) with columns `["individual", "class", "label", "label_gold"]`.
   - `manifest.json`: Input/output SHA-256 digests, dropped-construct counts, range-materialisation counts, label summaries, and timings (mirrored to `experiments/data/helis/manifest.json`).
