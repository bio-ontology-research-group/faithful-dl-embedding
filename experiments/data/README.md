# Experiment Datasets (`experiments/data/`)

This directory contains the deterministic dataset generators and committed small OWL splits used in the learnable geometric embedding experiments (Spec §5.1).

## 1. Synthetic Helly Suite (`tk3`, `tk4`, `tk5`, `tk6`)

Generated by `experiments/data/make_synthetic.py` into `experiments/data/synthetic/tk{k}.owl` (`k in {3, 4, 5, 6}`), namespace `http://mowl.borg/geo#`:

- Concept names `X_1, ..., X_k`.
- For each `i in 1..k`, a concept name `A_i ≡ ⊓_{j != i} X_j` representing the `(k - 1)`-fold conjunction of all `X_j` except `X_i`. For `k >= 4`, the `(k - 1)`-ary intersection is binary-normalised with shared auxiliary equivalence names `Aux_<idx_1>_..._<idx_m> ≡ left ⊓ right` so that `mowl.geometric.normalise` preserves both inclusion directions of each intermediate binary conjunction.
- Pairwise disjointness axioms `A_i ⊓ A_j ⊑ ⊥` for all `1 <= i < j <= k`.
- One declared unconstrained concept name `Z`.
- Task: `satisfaction` (no held-out validation or test axioms).

### Certificate Structure on `T_k`

- **`tk3` (`k = 3`)**: `A_1 ≡ X_2 ⊓ X_3`, `A_2 ≡ X_1 ⊓ X_3`, `A_3 ≡ X_1 ⊓ X_2`. All three pairwise conjunctions of `{X_1, X_2, X_3}` are directly named by `NF2` equivalences, so both `certificate_triangles(cm)` and `helly_check(cm, k_max=3)` return the unique non-degenerate certificate over `(X_1, X_2, X_3)`.
- **`tk4..tk6` (`k >= 4`)**: `T_k` names its `(k - 1)`-wise conjunctions rather than all three pairwise edges of an unsatisfiable 3-clique, and every 3-subset of `{X_1..X_k}` is satisfiable. Consequently, `certificate_triangles(cm)` returns `[]`, while `helly_check(cm, k_max=k)` finds the minimal unsatisfiable set of size `k` as a non-degenerate `HellyCertificate` with `c1=(X1,)`, `c2=(X2,)`, `c3=(X3, ..., Xk)` and `pairwise_names=(Aux_1_2, A2, A1)`.

## 2. Pizza-EL Subsumption Benchmark (`pizza`)

Generated by `experiments/data/make_pizza.py` from `~/tmp/gfe-data/pizza/pizza.owl` into `~/tmp/gfe-data/pizza-el/` (and mirrored into `experiments/data/pizza-el/`, ~326 KB total):

1. Normalise `pizza.owl` into its EL++ fragment via `mowl.geometric.normalise` (`662` normalised axioms across `109` concept names and `8` roles; `52` non-EL++ axioms dropped).
2. Build the canonical model `cm_full` of the full EL++ fragment (`106` satisfiable concept names including `owl:Thing`; `2` unsatisfiable concept names `CheeseyVegetableTopping` and `IceCream`).
3. Collect candidate asserted atomic subsumptions `NF1(A, B)` where `A != B`, `A, B not in {owl:Thing, owl:Nothing}`, neither `A` nor `B` is an auxiliary normalisation entity (`/aux` or `aux#`), and both `A` and `B` are satisfiable in `cm_full` (`86` candidate axioms).
4. Permute candidates with `numpy.random.default_rng(0)`. Because a `10 % / 10 %` split yields `9 < 20` test axioms, the split fractions are raised to `20 % / 20 %` per Spec §7, yielding `17` validation axioms (`valid.owl`), `17` test axioms (`test.owl`), and `628` remaining training axioms (`ontology.owl`, including `56` `NF1` axioms).
5. Write `ontology_deductive_closure.owl` containing all `435` non-trivial atomic subsumptions `A ⊑ B` (`A != B`, excluding `owl:Thing` and `owl:Nothing`) entailed by `cm_full` over satisfiable concept names.

## 3. GO and FoodOn Subsumption Benchmarks (`go`, `foodon`)

Loaded via `mowl.datasets.builtin.GOSubsumptionDataset` and `FoodOnSubsumptionDataset` with `data_root=~/tmp/gfe-data/mowl` (Chen et al., 2020 protocol). Each tarball provides `ontology.owl`, `valid.owl`, `test.owl`, and `ontology_deductive_closure.owl`.
